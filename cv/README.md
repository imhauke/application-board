# Your CVs

Put your two CVs here as PDFs (they are not committed):

- `swe.pdf`: the CV with your **production** project (a deployed service or product).
- `quant.pdf`: the same CV with your **low-level** project instead (a compiler, a kernel, systems work).

The board reads them on start and whenever they change: experience, projects, skills, languages and graduation date (`Expected graduation: June 2027`). `examples/cv/` has two example CVs showing the format it understands; to try the board with them, start it with `CV_DIR=examples/cv`.
