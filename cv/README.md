# Your CVs

Put your CVs here as PDFs; they are not committed:

- `swe.pdf`: with a project **in production**, for SWE, SRE/infrastructure, backend, product and applied AI roles.
- `quant.pdf`: the same CV with a **low-level** project instead, for compilers, C++, low-latency and quant roles.

What the board reads from them, and how to use a single CV, is in [the main README](../README.md#your-cvs).
